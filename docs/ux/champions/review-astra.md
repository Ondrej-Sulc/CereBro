Players may misread adjacent numbers or labels. Source hypothesis: fixed `grid-cols-3` inside nested padding in the hero metric container. Experiment: separate metric rows below a narrow breakpoint. Acceptance: all three complete values/labels have distinct, non-overlapping boxes at 320px/390px, without clipping or horizontal scroll; recheck after build change. Risk: taller metrics push navigation down; measure explicitly.
2. **T1, T7: Mobile champion name fractures within words.** 07 shows ABSORBI / NG MAN; 11 shows ABSOR / BING / MAN. This weakens scanning and uses extra height. Oversized expressive typography is a preference worth preserving; the ordinary word break is observed. Risk: weakening character/short names.
