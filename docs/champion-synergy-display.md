# Full synergy card display

The Synergies tab uses `groupChampionSynergyFamilies` after `buildChampionSynergyView` has selected the current champion, rarity and owned/incoming direction. The raw catalog cards remain separate for effect-source matching and detailed navigation.

First, `groupChampionSynergyCards` combines identical rarity imports when their full name/level, rendered bonus content (including glossary semantics), stacking flag, partner identities and catalog member identities match. This folds repeated imports such as Hulk (Ragnarok)'s incoming It's Complicated Lv. 3 cards into one bonus row. Different amounts, recipients or rules remain distinct rows.

Then explicit `Lv. N` variants of the same named family, partner set, catalog members and stacking flag share a card. Its partner header appears once, followed by rows in numeric level order. Each row preserves its complete bonus text, glossary help and correlated star requirements; values are not inferred or summarized into a range. Non-leveled names and unknown availability stay separate. If only one variant applies to the selected champion build, its original single-card presentation remains.

Availability remains explicit. Single-partner stars can be combined only when the current champion's star set is identical. Different current-champion stars and correlated multi-partner combinations retain separate availability rows. Unknown star metadata is not consolidated. The compact presentation uses continuous rows with the complete bonus text always visible. Portrait links have accessible names and hover/focus name help. Each row has a contextually named expander, with a shared list-level guide and a hover/focus tooltip instead of repeated visible wording. Single-variant rows expose full names and exact requirements in a closed-by-default associated panel, including on touchscreens. An unambiguous single rule also supplies hover/focus star help. Family panels provide the named partner legend; exact star requirements remain visible beside each level instead of implying a family-wide star range. Consecutive stars use compact ranges such as `4–7★`; gaps remain explicit, such as `2★, 4–5★, 7★`.

Grouped cards preserve every original catalog ID. Existing source links, URL fragments, focus and highlighting resolve to the relevant level row through stable aliases. Identical uniqueness notes appear once per family; differing notes remain with their rows. Search matches every level's name, partner or bonus, retains the whole matching family for comparison, and direction counts match displayed family cards. No catalog rows, original descriptions, effect-source records or reviewed overview summaries are changed.

Compact titles also show the native game synergy glyph when its imported `raw.texture` has a verified font outline. The glyph is decorative; an unavailable mapping leaves the title without an icon. Icon identity participates in both grouping passes so different icons are never borrowed from another row or level. Import IDs, source hashes and aliases remain unchanged. See [native synergy icon extraction](synergy-icons.md).

Expanded partner panels use full-name champion links and aligned exact star ranges. Separate availability groups preserve the correlation between this champion's stars and its partners' stars; missing metadata stays explicit. Family legends link to the named partners while level-specific stars remain beside each level. Escape closes either panel and restores visible focus to its expander below the sticky navigation. See the [requirements-panel comparison and verification](ux/champions/requirements-panels/notes.md).
