# Native synergy glyphs

Original vector outlines extracted from the game's `Marvel-Icons-Font`, bound by `BCGSynergyBonus.Texture`. Filenames contain the native Unicode codepoint and SVG content hash. See [extraction, provenance and refresh instructions](../../../../docs/synergy-icons.md) and [the exact source mapping](../../../../src/data/synergy-icons.json).

These assets are independent of champion portraits, classes and glossary/effect icon mappings. Unknown source textures have no replacement icon.
